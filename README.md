# Impinj R700 RFID 管理工具

该仓库当前包含两个项目：

- `ImpinjR700`：基于 WinForms 的桌面程序，用于连接 Impinj R700、查看标签数据、绘制 RSSI / Phase 曲线并导出报表。
- `mobile_app`：基于 Flutter 的 Android 移动端首版，用于在局域网内通过 `IoT Device Interface` 连接 R700、选择天线、开始/停止/定时读取，并实时查看标签与运行日志。

桌面版负责完整的分析、绘图与导出能力；移动端首版优先覆盖现场连接与基础读取流程，不复用 `OctaneSDK`，而是直接调用 R700 的 HTTPS API 与事件流接口。

## 📱 移动端（Flutter）

移动端工程位于 [mobile_app](mobile_app/)，当前面向 Android 首版，已实现以下能力：

- **安全连接**：输入读写器地址、用户名、密码后通过 HTTPS 连接；首次遇到新证书时，需要用户确认设备指纹。
- **读取控制**：支持连接/断开、天线多选、开始读取、定时读取、停止读取。
- **实时数据**：展示唯一标签数、总读取次数、当前状态，以及 EPC、天线、最新 RSSI、首次/最后读取时间等信息。
- **运行日志**：记录连接结果、开始/停止、自动停止、异常、事件流关闭等关键过程。
- **前台使用模型**：应用进入后台时会主动停止读取，并写入日志，避免后台持续盘存。

### 移动端接口说明

移动端直接调用 R700 `IoT Device Interface`，当前使用的核心接口如下：

- `GET /api/v1/system`
- `GET /api/v1/system/image`
- `GET /api/v1/openapi.json`
- `GET /api/v1/system/antenna-hub`
- `GET /api/v1/status`
- `POST /api/v1/profiles/inventory/start`
- `POST /api/v1/profiles/stop`
- `GET /api/v1/data/stream`

## ✨ 功能亮点

- **设备管理**：输入读写器 IP（默认 `192.168.15.2`）即可连接或断开，状态栏和日志实时显示结果。
- **读取控制**：支持选择天线端口、启停盘存、配置自动重连，多种异常情况都会写入运行日志。
- **标签总览**：主表格实时刷新 EPC、天线、RSSI、相位（rad）、读取次数、首次/最新时间等字段；底部统计面板展示唯一标签数。
- **双曲线绘图**：包含“信号曲线（RSSI）”与“相位曲线（Phase）”两个页签，按 `EPC + port` 分系列绘制，X 轴默认从 `0s` 起步并采用 `30s` 滚动窗口；历史绘图数据会持续保留，不再按点数裁剪。
- **连续绘图**：同一 `EPC + port` 系列保持连续连线，长时间未读取后再次上报也不会自动断线；同系列颜色保持一致。
- **图例与筛选**：支持启用 EPC 筛选，并可在白名单（仅保留勾选）与黑名单（排除勾选）间切换；图例默认位于左上角。启用筛选后，未参与绘图的记录不会进入历史数据源。
- **统计增强**：统计信息中按每条曲线实时计算 `RSSI 峰值 / 均值 / 方差`。
- **模拟信号测试**：内置模拟读数，可生成多 EPC（16 进制）与双天线数据，且同一 EPC 可被多个天线捕捉。
- **数据导出**：CSV / Excel 导出包含标签汇总与曲线采样；文件命名格式为 `RFID_yyyyMMdd_EPC.xxx`，多 EPC 使用 `MULTI`。导出直接基于表格绑定的历史数据源，因此会和当前筛选后的保留数据保持一致。
- **运行日志**：详细记录连接、读取、异常等事件，便于问题排查。

## 🚀 快速上手

1. 安装 .NET 8.0 Runtime / SDK，并确保电脑与读写器网络互通。
2. 运行 `ImpinjR700.exe`（或在 Visual Studio 内按 F5 调试）。
3. 在左上角输入读写器 IP，点击 **连接**；成功后状态条会变为绿色“已连接”。
4. 在右侧勾选需要启用的天线端口，点击 **开始读取**。
5. 实时查看：
   - **标签列表** 页签：表格数据 + 统计面板；
   - **信号曲线** 页签：RSSI 曲线，可滚轮缩放、框选放大。
6. 点击 **导出 CSV / 导出 Excel**，即可获得包含两张表（Tag Summary、Samples）的结果文件。
7. 如需重置，点击 **停止读取** 再点 **清空记录**。

> 小贴士：开启“自动重连”可以在读写器掉线后自动尝试恢复。

## 🗂️ 数据流说明

- 当前程序只有一份历史记录数据源，即 `BindingList<TagReadRecord>`。
- 标签表格、绘图和导出都直接使用这份数据源，不再维护额外的渲染缓存。
- 历史记录默认持续保留，不再按固定条数裁剪旧记录。
- 启用 EPC 筛选后，只有命中筛选条件的记录才会进入这份数据源；修改筛选条件时，不再命中的历史记录也会被同步移除。

## 📄 导出数据结构

无论 CSV 还是 Excel，都会包含以下两部分：

1. **Tag Summary**（标签汇总）
   - EPC、天线、最新 RSSI、最新相位、读取次数、首次读取时间、最后读取时间。
2. **Samples**（曲线采样）
   - EPC、时间戳、RSSI、天线、相位（rad）、读取次数（按照时间、EPC 排序）。

示例：

```
# Tag Summary
EPC,天线,RSSI (dBm),相位 (rad),读取次数,首次读取时间,最后读取时间
300833B2DDD9014000000000,天线1,-52.5,38.4,12,2024-05-16 14:02:18.153,2024-05-16 14:05:03.947
...

# Samples
EPC,时间,RSSI (dBm),天线,相位 (rad),读取次数
300833B2DDD9014000000000,2024-05-16 14:02:18.153,-58.1,天线1,36.2,1
300833B2DDD9014000000000,2024-05-16 14:02:19.204,-56.7,天线1,37.5,2
...
```

Excel 文件中同样会生成 `Tag Summary` 与 `Samples` 两个工作表。
