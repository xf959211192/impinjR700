# Impinj R700 RFID 管理工具

该项目是一个基于 WinForms 的桌面程序，帮助用户快速管理 Impinj R700 读写器，实现设备接入、标签采集、RSSI 信号曲线可视化以及数据导出等一系列工作。

## ✨ 功能亮点

- **设备管理**：输入读写器 IP（默认 `169.254.1.1`）即可连接或断开，状态栏和日志实时显示结果。
- **读取控制**：支持选择天线端口、启停盘存、配置自动重连，多种异常情况都会写入运行日志。
- **标签总览**：主表格实时刷新 EPC、天线、RSSI、相位、读取次数、首次/最新时间等字段；底部统计面板展示唯一标签数与累计读取次数。
- **RSSI 曲线**：集成 ScottPlot，可在“信号曲线”页按 EPC 绘制多条 RSSI 曲线（默认保留最近 5 分钟、每条最多 500 个采样点），支持鼠标滚轮缩放、拖拽移动。
- **数据导出**：CSV / Excel 导出同时包含标签汇总（Tag Summary）与曲线采样（RSSI Samples）两类数据，方便做离线分析。
- **运行日志**：详细记录连接、读取、异常等事件，便于问题排查。

## 🚀 快速上手

1. 安装 .NET 8.0 Runtime / SDK，并确保电脑与读写器网络互通。
2. 运行 `ImpinjR700.exe`（或在 Visual Studio 内按 F5 调试）。
3. 在左上角输入读写器 IP，点击 **连接**；成功后状态条会变为绿色“已连接”。
4. 在右侧勾选需要启用的天线端口，点击 **开始读取**。
5. 实时查看：
   - **标签列表** 页签：表格数据 + 统计面板；
   - **信号曲线** 页签：RSSI 曲线，可滚轮缩放、框选放大。
6. 点击 **导出 CSV / 导出 Excel**，即可获得包含两张表（Tag Summary、RSSI Samples）的结果文件。
7. 如需重置，点击 **停止读取** 再点 **清空记录**。

> 小贴士：开启“自动重连”可以在读写器掉线后自动尝试恢复。

## 🧱 项目结构与依赖

| 组件 | 说明 |
| --- | --- |
| `Form1` | 主窗口逻辑，负责连接、读取、曲线绘制和导出 |
| `Form1.Designer` | WinForms 设计器生成的布局文件 |
| `Form1.AntennaSelection` | 天线配置读取与保存的辅助逻辑 |
| `AntennaConfigurationForm` | 单独的天线配置对话框 |
| `ReaderInfo` | 读写器信息展示对话框 |

### NuGet 依赖

| 包名 | 版本 | 用途 |
| --- | --- | --- |
| `OctaneSDK` | 5.0.0 | Impinj 官方 SDK，用于与 R700 通讯 |
| `ClosedXML` | 0.104.0 | Excel (`.xlsx`) 导出 |
| `ScottPlot.WinForms` | 5.1.57 | RSSI 曲线绘制 |

> ScottPlot 会带来 OpenTK / SkiaSharp 等依赖，构建时会看到 NU1701 兼容性警告，实测可忽略。

## 📄 导出数据结构

无论 CSV 还是 Excel，都会包含以下两部分：

1. **Tag Summary**（标签汇总）
   - EPC、天线、最新 RSSI、最新相位、读取次数、首次读取时间、最后读取时间。
2. **RSSI Samples**（曲线采样）
   - EPC、时间戳、RSSI、天线、相位、读取次数（按照时间、EPC 排序）。

示例：

```
# Tag Summary
EPC,天线,RSSI (dBm),相位 (deg),读取次数,首次读取时间,最后读取时间
300833B2DDD9014000000000,天线1,-52.5,38.4,12,2024-05-16 14:02:18.153,2024-05-16 14:05:03.947
...

# RSSI Samples
EPC,时间,RSSI (dBm),天线,相位 (deg),读取次数
300833B2DDD9014000000000,2024-05-16 14:02:18.153,-58.1,天线1,36.2,1
300833B2DDD9014000000000,2024-05-16 14:02:19.204,-56.7,天线1,37.5,2
...
```

Excel 文件中同样会生成 `Tag Summary` 与 `RSSI Samples` 两个工作表。
